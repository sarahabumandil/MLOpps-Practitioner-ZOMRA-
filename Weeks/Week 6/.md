Week 6 (Sat, Sep 19 - Fri, Sep 25)
Observability & Drift Detection — Know Before Your Users Do
A model doesn't break like code does. It doesn't throw an exception, it doesn't return a 500 error, and it doesn't page anyone at 3am. It just silently becomes wrong — and you find out when a user complains, a business metric drops, or a stakeholder asks why the predictions look strange.

This module teaches you how to build the monitoring layer that catches model degradation before users do. You will learn the four types of drift that kill production models, the statistical methods used to detect each one, and how to instrument your serving layer with the tools that production ML teams actually use — for both classical ML and LLM systems.

By the end of this module you will have a complete observability stack running: Evidently AI generating weekly drift reports inside an Airflow DAG, PSI scores flowing into Prometheus gauges, a Grafana dashboard alerting when any feature drifts beyond threshold, and Langfuse tracing every LLM call with RAGAS quality scores attached.
